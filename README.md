# BizNest Complete Starter Project

BizNest is a business website and e-commerce builder.

## Included
- Landing page
- Login and registration demo
- Business dashboard
- Product management
- Website builder preview
- Orders
- Customers
- Analytics
- Settings
- Supabase starter configuration
- Supabase SQL schema

## Important
The demo version uses browser localStorage for immediate testing.
For production, replace demo authentication and storage with Supabase.

## Setup
1. Extract ZIP.
2. Open the project folder in VS Code.
3. Upload files to a GitHub repository.
4. Add Supabase URL and Publishable Key in assets/js/supabase-config.js.
5. Run database/supabase.sql in Supabase SQL Editor.
